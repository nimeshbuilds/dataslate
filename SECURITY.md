# Security

DataSlate is an early foundation, with no production-qualified release or supported release branch yet. Live identity, cloud storage, catalog policy and engine integrations require qualification before use with sensitive workloads. Current implementation and validation limits are recorded in [the coverage inventory](docs/implementation/coverage.md) and [validation record](docs/implementation/validation.md).

## Reporting a vulnerability

Use GitHub's private **Report a vulnerability** flow on the repository's [Security page](https://github.com/NimeshBuilds/dataslate/security). Include the affected revision, reproduction steps, expected/actual behavior and the potential impact. Use synthetic examples; do not include real tokens, customer datasets or credentials.

If private reporting is unavailable, open a minimal issue requesting a private contact channel without vulnerability details. Do not publish exploit details or sensitive data in public issues. The project does not currently promise a response-time SLA.
