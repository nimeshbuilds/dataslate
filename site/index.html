Your stack, with a clear owner.

A flexible deployment model is central to the design. Use compatible services you already operate, or let DataSlate manage selected dependencies.

Connect your identity provider, PostgreSQL, object store and compatible Spark operator. Existing services keep explicit ownership.

  • Integration settings and credential references
  • Compatibility and health checks
  • No silent replacement of cluster operators

Choose a managed dependency profile with declared versions, lifecycle and resource requirements. A self-contained distribution is on the roadmap.

  • Helm-based Kubernetes deployment
  • Explicit dependency and upgrade ownership
  • Backup, recovery and qualification gates

View repository ↗Deployment guide ↗

Development requires the Go version in api/go.mod, Node 22.19+ and npm. Start the API and workspace in separate terminals. This starts source authoring with disposable development storage. Backend execution requires configured services and grants; it does not provision cloud resources.

Development quickstart
git clone https://github.com/NimeshBuilds/dataslate.git
cd dataslate
make dev-api

Leave the API running, then open another terminal.

cd dataslate/web
npm ci
npm run dev

From the directory where you cloned the repository, open the Vite URL printed in this terminal.
